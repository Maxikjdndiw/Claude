# Photo manifest for Maxi's personal website

36 unique photos, compressed to max 1800px on the long edge (JPEG, quality 80).
Each photo is listed once. Captions describe what is visible. Place names are the owner's trip memories and may need correcting. Suggested placement is a starting point, not a rule.

Treatment notes from the owner:
- Nights out (club and party shots): keep them dark, grainy and slightly blurry on purpose. They should feel like unstaged film snapshots, not influencer content. They also keep other people's faces unidentifiable.
- School ceremony photo: show it small. It is the first photo of a school collection that will grow later.
- All other photos: one shared warm, slightly faded film filter plus light grain, so the set feels consistent.
